# CUDA 2D Euler solver
<p>
  A CUDA-based implementation of the <strong>2D Euler equations</strong>, with
  GPU parallelization currently focused on the <strong>LLF numerical flux</strong>
  and <strong>timestep computation</strong> subroutines using CUDA kernels.
  The project is <strong>work in progress</strong>, with further development
  and optimization planned.
</p>
<p>
  <strong>Note:</strong> Create a <code>build/</code> directory before compiling.
  This directory is used to store the generated object and build files.
</p>
